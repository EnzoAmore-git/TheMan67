# TheMan67

Сайт барбершопа Виктории Серединой в Смоленске: знакомство с мастером, услуги, портфолио и запись.

В работе я пересмотрел композицию и тексты, разработал визуальный образ и адаптировал страницы для телефона. Сохранил содержание услуг и каналы записи, уделил внимание доступности, галерее и поисковому представлению сайта.
