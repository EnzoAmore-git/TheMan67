# TheMan67

Барбершоп Виктории Серединой в Смоленске. Статический сайт: услуги и цены, знакомство с мастером, девять работ, адрес и запись через MAX, Telegram или телефон.

Редизайн сохраняет порядок разделов и существующие якоря. Вместо HTML-монолита — семантическая разметка, отдельные стили и JavaScript-модули. React, CMS и серверные зависимости не требуются.

## Запуск и проверка

Нужен Node.js 22 или новее. Установка пакетов не нужна.

```sh
npm run dev
npm run check
npm run build
npm run preview
```

Dev и preview используют http://127.0.0.1:4173; запускайте их по очереди. Порт меняется переменной окружения PORT. Preview показывает production-сборку из dist/.

`check` проверяет структуру разделов, якоря, локальные ресурсы, количество фотографий, совпадение цен с JSON-LD и синтаксис JavaScript. Браузерные проверки и результаты Lighthouse описаны в [docs/QA.md](docs/QA.md).

## Дизайн и медиа

Графит, тёплый светлый фон, киноварный акцент, Manrope и Cormorant Garamond. Большая типографика, строки прайса вместо одинаковых карточек, полноценная мобильная композиция.

Hero создан с помощью генерации изображений. Это художественная визуализация, не фотография работы Виктории. Видео не используется: при первом появлении изображение плавно приближается к финальному кадру, заголовок появляется через transform/opacity. Постоянного движения нет. В prefers-reduced-motion эффекты отключаются. Изображение hero доступно в трёх размерах: около 22 / 46 / 108 КБ.

По запросу владельца портрет Виктории и широкий кадр для «О нас» сгенерированы на основе предоставленных фотографий с сохранением внешности. Девять работ взяты из текущего портфолио production. Оригиналы локальных исходников сохранены. Информация о происхождении: [docs/MEDIA.md](docs/MEDIA.md).

Без JavaScript контент, навигация и ссылки записи доступны; фотографии открываются отдельными файлами. При JavaScript галерея использует нативный dialog: кнопки, клавиатура, Escape, возврат фокуса, свайп.

## SEO

Уникальные title/description, один H1, заголовки H2–H3, canonical, Open Graph, Twitter Cards, sitemap.xml, robots.txt и HairSalon с адресом, телефоном, расписанием и услугами. Нет вымышленных оценок, отзывов или квалификаций. Цены в HTML и Schema.org проверяются одной командой.

Все SEO-URL настроены на https://www.theman67.ru/. Для отдельного публичного staging настройте noindex на уровне окружения; не публикуйте индексируемую копию с другим доменом. После выкладки проверьте HTTPS, canonical-редиректы и доступность robots/sitemap, отправьте sitemap в Яндекс Вебмастер и Google Search Console. Полевые Core Web Vitals требуют данных после реальной публикации.

## Публикация

1. Выполнить check и build.
2. Загрузить **содержимое dist/** в документ-корень действующего хостинга, сохранив резервную копию текущего сайта.
3. Проверить приоритет index.html относительно существующего index.php, который в исходниках является стартовой страницей Beget.
4. Проверить ресурсы, запись, карту, canonical и счётчик на домене.
5. При необходимости восстановить прежний комплект из резервной копии хостинга.

Архивы, документацию, tools/ и исходные необработанные медиа на хостинг не загружать. Репозиторий не включает автоматический деплой, изменения DNS или настройки Beget.

- Новый снимок портфолио: thumbnail + полная WebP-версия, содержательный alt, размеры и ссылка.
- Счётчик Яндекс Метрики 109624419 сохранён. Он загружается только на theman67.ru/www.theman67.ru, а не в локальном preview.
